# 密码保险库 - 浏览器扩展配套插件

本插件是全栈密码管理器 **「密码保险库 - Password Vault」** 的官方配套 Chrome / Edge 浏览器插件（基于 Chrome 最新 **Manifest V3** 规范构建）。

插件 UI 全面重构，视觉风格、设计系统 Token、组件样式（按钮、卡片、分段选项卡、密码强度计、弹窗提示）与 Web 服务端项目（Tailwind CSS + shadcn/ui）保持 100% 像素级一致。

---

## 🎨 UI 与设计系统一致性说明

- **品牌视觉标识**：采用与 Web 端仪表盘完全一致的 `ShieldCheck` 盾牌标识、**「密码保险库」** 标题以及 **「私密 · 安全 · 同步」** 副标题。
- **色彩与主题适配**：
  - 精确对齐 `app/globals.css` 中的 `background`, `foreground`, `card`, `primary`, `muted`, `border` 等 OKLCH / CSS 变量。
  - **支持亮色 / 暗色模式无缝切换**：可跟随系统或在插件顶部直接点击太阳/月亮图标一键切换，弹窗与网页注入组件均完美自适应。
- **卡片与排版**：
  - 密码记录卡片复刻 Web 端的首字母徽章容器（`entry.site.charAt(0).toUpperCase()`）、排版层级、复制反馈及快速填入按钮。
  - 密码生成器采用与服务端组件 `components/password-strength.tsx` 相同的 **5 段式动态强度条**（非常弱、弱、一般、强、非常强）。
  - 选项卡采用 shadcn/ui 经典的胶囊分段滑动器（Segmented Control）样式。

---

## ✨ 核心功能特性

1. **极简初始化**：首次打开插件，仅需填写 **API 地址**（如 `http://localhost:3000`）与 **API Key 密钥**（在 Web 端「API 密钥」中生成），点击测试并保存即可直接使用。
2. **表单自动检测与快捷注入**：
   - 自动识别网页登录与注册输入框，并在右侧优雅嵌入微型钥匙盾牌图标。
   - 点击即可弹出匹配当前域名的账号快速填入列表，同时提供「生成随机强密码」快捷操作。
3. **网页密码自动捕获与浮动横幅**：
   - 当在任意网站注册或登录提交表单时，插件在页面顶部滑出精致的横幅：「是否将此密码保存到密码保险库？」，点击即可一键同步入库。
4. **强随机密码生成器**：
   - 自定义 8~64 位长度与字符组合，内置 5 段式强度评估。
   - 支持一键填入当前聚焦输入框，或通过鼠标右键菜单快速生成并填入。
5. **全库检索与网页控制台直达**：
   - 在弹窗内支持全库密码实时模糊搜索与快速复制。
   - 提供直达完整 Web 仪表盘的快速入口。

## 🚀 安装与加载步骤

1. 打开 Chrome、Edge 或基于 Chromium 的浏览器，在地址栏输入：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 打开右上角的 **「开发者模式」** (Developer mode) 开关。
3. 点击左上角的 **「加载已解压的扩展程序」** (Load unpacked)。
4. 选择本项目中的 [`extension/`](file:///c:/Users/aaajn/Documents/GitHub/Full-stack-key/extension/) 文件夹。
5. 在浏览器工具栏固定「密码保险库」插件图标。
6. 点击插件图标，输入你的 API 地址和 API Key，点击 **「测试并连接保险库」** 即可。
