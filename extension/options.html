如何获取 API Key 密钥？

  1. 打开你的密码保险库网页端（本地默认为 http://localhost:3000）。
  2. 登录进入控制台，点击侧边栏或进入 「API 密钥」 页面。
  3. 点击「创建新密钥」，生成并复制以 pm_live_ 开头的密钥串。
  4. 粘贴到上方输入框后点击「测试连接」并保存即可完成绑定。
